# Classificação de Vendedores

Trabalho da disciplina Inteligência de Negócios
Curso Análise e Desenvolvimento de Sistemas - IFTM campus Patrocínio

## Implementação algoritmo Decision Tree para classificação de dados

O trabalho consiste em um formulário para coletar informações do vendedor e alimentar o algoritmo de Decision Tree.

A Decision Tree foi gerada no programa **KNIME Analytics Platform** utilizando uma base de dados real.

O front-end foi desenvolvido em **React.js** com **Styled Components** e o back-end em **Node.js** com **TypeScript**.

### Pré-requisito para executar o projeto

- Node.js
